This app is being created to train my skills and know my knowledge about web development.
It's app for sport training sessions, that may help people improve their results in the gym.

## Planned features
Многопользовательское приложение: регистрация и вход, у каждого свои данные.
Тренировка: дата, заметка, упражнения, у каждого подходы × повторы × вес. Турник с доп. весом укладывается в ту же модель.
Справочник упражнений: общий плюс свои.
Прогресс: личные рекорды (макс. вес, расчётный 1RM) и график по упражнению.
Mobile-first: удобно заполнять в зале с телефона.
Интерфейс на английском с переключением на русский в настройках.
