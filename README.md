# Ambarkuyan

A mobile-first workout diary for logging gym sessions, tracking personal records and seeing your progress over time.

> **Status:** work in progress — built as a full-stack learning and portfolio project.

## Planned features

- **Accounts** — sign up and log in; each user sees only their own data
- **Workouts** — log date, notes and exercises with sets × reps × weight (weighted pull-ups included)
- **Exercise library** — built-in exercises plus your own custom ones
- **Personal records** — max weight and estimated one-rep max (1RM) for each exercise
- **Progress charts** — see how each exercise improves over time
- **Mobile-first design** — quick to fill in between sets at the gym
- **Localization** — English interface, Russian available in settings

## Tech stack (planned)

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL, Prisma
- **Testing:** Vitest, React Testing Library, Playwright
- **Infrastructure:** Docker, GitHub Actions
